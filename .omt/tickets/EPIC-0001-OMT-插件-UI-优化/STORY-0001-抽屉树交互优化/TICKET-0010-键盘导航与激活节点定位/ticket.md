## 描述

提升大树场景的浏览效率：完整的键盘导航与一键定位激活节点。

## 键盘导航（焦点在树内时）

| 按键 | 行为 |
|------|------|
| ↓ / ↑ | 焦点移到下一个/上一个**可见**行（收起节点的子树不参与） |
| → | 焦点行有子节点且已收起 → 展开；已展开 → 焦点移到第一个子节点 |
| ← | 焦点行展开中 → 收起；已收起或为叶子 → 焦点移到父节点 |
| Enter | 打开焦点节点详情（等价于点击行：select → 右侧详情面板） |
| Home / End | 跳到第一个/最后一个可见行 |

- 焦点进入：点击树任意行后树获得焦点；焦点行样式 = 品牌色描边 + 微弱底色，与"激活行"（选中底色）视觉区分
- 与搜索/过滤联动：过滤条件变化后焦点落到第一个匹配行；导航只在可见行集合内移动
- 焦点逻辑抽成纯函数（给定可见行序列 + 当前焦点 + 按键 → 新焦点/展开动作），单测覆盖

## 定位激活节点

- 工具栏新增"定位"按钮（◎ 图标，无激活节点时禁用）
- 点击后：展开激活节点的**全部祖先**（覆盖折叠记忆）→ 平滑滚动到该行居中 → 焦点落在该行并短暂高亮提示
- 若激活节点正被过滤条件隐藏：先清除过滤再定位

## 验收标准

- 纯键盘可完成浏览（移动/展开/收起）与打开详情，全程无需鼠标
- 一键定位激活节点（含跨折叠层级、含被过滤的场景）
- 焦点态与激活态样式一眼可辨
