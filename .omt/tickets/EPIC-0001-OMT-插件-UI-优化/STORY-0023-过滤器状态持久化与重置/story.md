## 能力结果
ticket tree 的过滤/排序/显示状态跨页面刷新持久保存，且可一键重置，用户不必每次打开面板重新配置筛选。

## 使用者
- 用抽屉/浮窗/Tab 三种壳浏览 ticket 树的用户

## 范围
- 过滤器状态（搜索词、归档开关、类型/状态/优先级多选、编号显示、排序）自动保存到当前 workspace 的 .omt 目录
- 下次加载面板（含刷新页面）时恢复已保存状态
- 过滤器面板末尾靠右新增 reset 按钮，重置后立即更新已保存数据
- 无 .omt 工作区时回退到全局 home 存储

## 非范围
- 折叠状态（已有 localStorage 记忆）迁移
- 跨设备/跨用户同步
- DocPanel 或 run 区块的状态持久化

## 验收标准
- 修改任意过滤器后刷新页面，状态恢复一致
- reset 后面板立即回到默认视图且保存文件同步更新
- 损坏/缺失的保存文件回退默认值，不阻塞面板加载
