# @omt/client-ts

TypeScript protocol bindings for the OMT JSON-RPC protocol, generated from the
JSON Schema documents in [`schema/`](../../schema) — the single source of truth
shared with the Rust bindings in `crates/omt-contracts` (KTD2, R3, R16).

Everything under `src/generated/` is generated by `scripts/gen-bindings.mjs`
(`pnpm gen` at the repository root); do not edit it by hand.

## Wire conventions

- JSON fields are camelCase (`homeId`, `nodeId`); enum values keep the domain's
  snake_case spelling (`in_progress`, `awaiting_confirmation`).
- Every public reference carries a stable `homeId` matching `^h_[a-z0-9]{6,}$`
  (R4).
- Errors travel as JSON-RPC error objects whose `data` is a `Problem`:
  assert on `code` and `details`, never on `message` (R5).
- Wire objects tolerate unknown fields so additive schema changes stay
  compatible with older peers. Note that TypeScript cannot enforce string
  patterns at compile time — `HomeId` etc. are type aliases; validate
  patterns at runtime where required (the Rust bindings do enforce them).

## Development

```sh
pnpm install                      # from the repository root
pnpm gen                          # regenerate src/generated from schema/
pnpm --filter @omt/client-ts exec tsc --noEmit
npm pack --dry-run                # inside packages/client-ts
```
